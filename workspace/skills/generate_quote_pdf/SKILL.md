# generate_quote_pdf — 報價單 PDF skill

## 我什麼時候會用這個 skill

step 13——廖老闆 GATE ④ 簽核後，我 call 這個 skill 產生報價單 PDF，然後 call `send_email` 把 PDF 附件寄客戶。

## 怎麼呼叫

```
exec bash skills/generate_quote_pdf/cli.sh
```

**stdin**：

```json
{
  "order_id": "QUO-2026-0001",
  "customer_name": "昕叡電子有限公司 Shin Tech.",
  "customer_email": "sunnxebusiness@gmail.com",
  "product_name": "Anti-Static Silicone Rubber Roller A1",
  "product_name_zh": "矽膠抗靜電包膠輪 A1",
  "qty": 200,
  "unit_price_twd": 1612,
  "total_twd": 322400,
  "lead_days": 14,
  "supplier_choice": "大同精密表面",
  "terms": "30% T/T deposit upon order confirmation, 70% before shipment. Anti-Static spec verified per ESD-S20.20. Lead time counts from deposit receipt.",
  "signed_by": "老闆（GatherEase AI agent LINE 簽核）"
}
```

**stdout**：

```json
{
  "status": "generated",
  "order_id": "QUO-2026-0001",
  "pdf_path": "data/orders/QUO-2026-0001/quote-QUO-2026-0001.pdf",
  "pdf_size_bytes": 18432,
  "page_count": 1,
  "generated_at": "2026-05-26T01:30:00.000Z"
}
```

## PDF 設計

- A4 直式
- Header: `QUOTATION` (24pt) + GatherRoller tagline
- Customer block: Order ID / Date / Customer / Email
- NVIDIA green 分隔線 (#76B900)
- Quotation Details: Product / Qty / Unit Price / Total / Lead Time
- Terms & Conditions
- Signature footer: Approved by + signed_at
- Footnote: 「This quotation is generated by GatherEase AI assistant (powered by NVIDIA Nemotron + NemoClaw governance). All actions audit-logged.」

## 規矩

- 主要英文（PDFKit 內建 PostScript fonts 對 CJK 有限）；中文文字塞 `product_name_zh` 等個別欄位用內嵌字型
- 金額用 `NT$ XXX,XXX` 格式 (千分位)
- PDF 寫到 `data/orders/<order_id>/quote-<order_id>.pdf`，跟 order JSON 同 dir
- 第一次跑會 lazy install `pdfkit` npm package (~5s)
- 完成後**不要自動寄信** — 另外 call send_email 帶 attachments
